# Akshat Mehra — Portfolio

Personal portfolio built with Next.js, TypeScript, and Tailwind CSS.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Update your details

Edit `src/data/portfolio.ts` — fill in email, phone, LinkedIn, GitHub, job dates, university, and project links when ready.
